Bind each edit to the layout region with the same Target label. Immediately before that region's desc, write an edit list. Keep elements.reference_edits grouped by Source reference_id frame_N with the original remove arrays, including empty groups, but omit the edit key because edits are now in layout. Each remove describes Source content absent from the Target with reference_label when provided, its Source reference_bbox (XYXY/1000), and instruction, in that order. Use Source label identifiers for cross-image grounding. Include the annotated edits inline; represent unchanged content in the complete Target layout without inventing extra edit actions or provenance fields. Follow the original edit instruction and the supplied Target aspect ratio. Output only the JSON object.
